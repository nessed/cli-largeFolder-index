## What the rehearsal found

Three rehearsals in throwaway temp copies, each from a new directory, all deleted.

**Two blockers, both fixed, both the same shape.**

- **F-02** (`c0442de`) — the installer registered the pages database as the hardcoded
  development rung `s2_fts5/harness_15000.db`, which does not exist in a portable install.
  Every command `CLAUDE.md` prints runs with no `--db` and no `--shelf`, so the very first
  one a stranger reaches died with `sqlite3.OperationalError: unable to open database file`.
  Fixed by plumbing `--db` through exactly as `--shelf-dir` already was. Five tests.
- **F-17** (`43ed356`) — `INSTALL.md`'s "Check the build" command exits 1 on any folder
  that is not the 15,000-file rung, because `--expect-pages` defaults to that rung's page
  count. Document only: the command now prints `--expect-pages 0` and says what it means.
  Four tests.

**The finding behind both is larger than either.** `p10_cleanroom.py` passes `--db`,
`--shelf` and `--expect-pages 0` on every call. Seven nights of gates therefore measured the
engine and never once ran the commands a reader of `INSTALL.md` would run. The harness knew
things the document did not say, and every green gate sat on top of that.
