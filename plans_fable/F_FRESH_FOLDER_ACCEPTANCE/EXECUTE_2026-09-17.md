## 0. Why this exists — read once, then work

This repository asks one question: can you point Claude Code at a folder of research PDFs,
ask a vague question in ordinary language, and get back the actual number with the file and
page it came from, or an honest "not in here"? Seven nights of pre-registered gates say
the machinery works in pieces. The last night (Plan E, branch `phase10-trust-and-repro`)
proved something narrower: a self-contained package, `dist/retrieval-portable-<commit>/`,
installs from scratch in a clean room, builds the same index twice, works on a second
folder (Gate R2 PASS), and never reads the development repo while doing so (Gate R3 PASS).

Every one of those installs was driven by a harness script that knows the engine inside
out (`corpus-lab/bin/p10_cleanroom.py`). **Nobody has yet followed `INSTALL.md` as a
stranger.** Ali's professor ("sir") will be a stranger. So before the next experiment (the
adversarial professor folder), Ali wants to sit down as sir would: a fresh folder on the
Desktop, `research/` holding only raw documents, `engine/` holding only the package, and
the package's own `INSTALL.md` as the only guide. The rule for that run is:

> If you need knowledge that is not in the package's INSTALL.md to make it work, that is a
> usability bug.

**Your job is to build the stage, not to act the play.** Ali runs the manual test himself.
You:

1. rebuild the package from the current HEAD commit;
2. stage `C:\Users\Ali\Desktop\portable-test\{research, engine}` and leave it untouched;
3. do a **dress rehearsal** in a throwaway copy, following `INSTALL.md` literally as a
   stranger, and log every place the document was not enough;
4. fix only what makes the test *impossible* (defined in section 6), never what is merely
   awkward — awkward is what the test exists to find;
5. record all of it the way every other phase in this repo is recorded, and commit.

Deliverable at the end: a Desktop folder Ali can open cold, a one-page scorecard he fills
in as he goes, and a findings file that already lists what you predicted and what the
rehearsal actually hit.
